## Use when

- API map, request/DI flow, commands → read [server/README.md](README.md)
- Deep-dives → read `server/docs/` · behavior specs → read `server/specs/` ·

## Stack & run

- Fastify 5 + Drizzle ORM + Postgres/pgvector, TypeScript 5.7, Vitest 2
- `pnpm dev` (:3001) · `pnpm build` (tsc) · `pnpm test` · `pnpm typecheck`
- `pnpm db:generate` / `pnpm db:migrate` / `pnpm db:seed`

## Where things are

- `src/modules/<name>/` — one Fastify plugin per feature (routes + service),
  registered statically in `src/modules/index.ts`
- `src/platform/` — `config.ts` (env/config), `container.ts` (DI container)
- `src/adapters/` — ports behind the DI container (llm, github, git, astgrep,
  secrets, tokenizer, embedder, …); `src/adapters/mocks.ts` swaps them in tests
- `src/db/` — Drizzle schema + migrations (schema already has tables for
  not-yet-built course-lesson features — leave them empty, don't backfill)
- `src/modules/repo-intel/` — the codebase indexer (symbols + import graph → repo map)
- `src/vendor/shared/` — vendored Zod contracts, see [../CLAUDE.md](../CLAUDE.md)

## Conventions (not obvious from code)

- Routes declare Zod `params`/`body` via `fastify-type-provider-zod` —
  validation is schema-first (422 before the handler runs); don't hand-roll
  `Schema.parse(req.body)` inside a handler.
- Plugins (helmet/cors/rate-limit/SSE) register before feature modules —
  register new modules after the plugin block in `src/modules/index.ts`.
- New adapters go behind the DI container (`platform/container.ts`) with a
  mock counterpart in `adapters/mocks.ts` — services never call an external
  adapter directly.
- Migrations are **not** applied on boot — `pnpm db:migrate` is manual.
- The global rate limit (120/min) is disabled under `NODE_ENV=test`.
- `*.it.test.ts` files spin up a real Postgres via testcontainers and
  self-skip without Docker — never add DB-backed assertions to a file that
  doesn't use that suffix.
- The prompt-injection defense (`INJECTION_GUARD`, in `reviewer-core`) is the
  only defense by design — don't add keyword/denylist scanning of PR content
  here.

## Do not touch

- `clones/` — gitignored git checkouts, regenerated by the repos module;
  never hand-edit or commit.
- `src/vendor/shared/` — mirror `client/src/vendor/shared/` exactly; don't
  let the two diverge.
